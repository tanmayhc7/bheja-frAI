Learn the ideas behind AI by moving them around

Every one of the 20 phases now has a starter lesson. The deepest coverage so far is setup, the little math you need, and building with language models (search, RAG, tool calling, testing and cost). Most lessons have a short animation or video, and all have something to drag or click, then two questions. The material follows the open-source course AI Engineering from Scratch, and more phases will be added to this page.

Use your coding agent as a tutor

Needs Node.js, npx and a coding agent that supports skills. It asks which agent and scope to install into.

npx skills add rohitg00/ai-engineering-from-scratch

Run the lesson code

Clone the repo, then run the first math lesson. It needs no extra packages.

git clone https://github.com/rohitg00/ai-engineering-from-scratch.git cd ai-engineering-from-scratch python3 phases/01-math-foundations/01-linear-algebra-intuition/code/vectors.py
